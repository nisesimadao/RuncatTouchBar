## Capture guidance for future refreshes

- Use a physical Touch Bar Mac and the release-candidate build.
- Keep private notifications, usernames, file paths, and unrelated app content out of frame.
- For the process-monitor screenshot, choose ordinary applications and avoid sensitive process names.
- Keep the Control Strip context visible; the important point is that RuncatTouchBar coexists with Apple's controls.
- Keep the expanded monitor readable rather than trying to fit every optional metric into one shot.
- Use real hardware captures for release documentation instead of generated or mock Touch Bar screenshots.
